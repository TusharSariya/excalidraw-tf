## Part I — Inherited decisions (pivot → rounds 1–7)

- **SDEC-1 · 2026-06-23→07-04 · Build a NEW engine (rcll-v2 → Strata); do not fix RCLL in place.** RCLL's host is per-container recursion (Sander's documented anti-pattern) with a readability ceiling from the cyclic-provider dense-rank collapse; the debt is the toggle/config surface. Rejected: stay-and-prune (keeps the exoskeleton). _(pivot memo; assessment §2.2/§2.5; architecture-decision Options A–B; v2.0 D2′)_
