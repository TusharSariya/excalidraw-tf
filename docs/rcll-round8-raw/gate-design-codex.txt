## Proposed metric family

Let \(G=(V,E)\) be the declared, non-aggregated TFD graph. Each edge has its canonical true-direction key and rendered world-coordinate polyline \(p_e=(p_0,\dots,p_m)\). Remove zero-length segments. Define

\[
\operatorname{turn}(a,b)=\frac{180}{\pi}\arccos(\operatorname{clamp}(a\cdot b,-1,1)),
\]

where both vectors are oriented in the path-traversal direction; straight continuation is \(0^\circ\).

The general Goodhart warning is real: drawings can be morphed toward arbitrary shapes while preserving one or several conventional quality metrics. Strata’s rank pinning and hull containment remove much of that paper’s free 2-D relocation space, but do not constitute a proof; the defense must remain scoped to structural invariants, all-edge path coverage, and several non-substitutable task metrics. [van Wageningen, Mchedlidze & Telea 2025](https://arxiv.org/abs/2508.15557).

## Path-level metrics for impact tracing

**Path population.** Build \(G\) from true-direction canonical TFD edges, independent of the rendered arm. Canonically sort nodes and edges.

Use deterministic edge-anchored walks so every dependency edge is represented:

1. For each canonical edge \(e=(u,v)\) and replica \(r\in\{0,1,2,3\}\), initialize path \([e]\).
2. Extend alternately forward and backward until \(L=8\) edges or both ends are blocked. Forward candidates are outgoing edges from the tail; backward candidates are incoming edges to the head.
3. Never repeat a vertex, so cycles terminate as simple paths.
4. Candidate choice uses canonical ordering plus a fresh `mulberry32(FNV1a32("20260704\0" + edgeKey + "\0" + r + "\0" + side + "\0" + step))`.
5. Evaluate both the downstream ordering and its exact upstream reversal.
6. Keep paths grouped by anchor edge; deduplicate only within the same anchor/replica. The path key is `anchorKey + replica + orientation + ordered edge keys`.

At P1 this yields at most \(145\times4\times2=1{,}160\) path observations before within-anchor deduplication. Single-edge paths contribute to crossing/angle/stretch; continuity, fan and geodesic metrics require at least two edges.

**Exact path formulas.**

For \(P=(v_0,e_1,v_1,\dots,e_k,v_k)\):

\[
C(P)=\sum_{i=1}^{k-1}\operatorname{turn}
  \left(t^-_{e_i,v_i},t^+_{e_{i+1},v_i}\right).
\]

The tangents are the last and first nonzero rendered segments after orienting each polyline in traversal direction.

\[
X(P)=\#\{\{e,f\}:e\in P,\ f\in E,\ e\ne f,\ e\text{ and }f
\text{ properly cross}\}.
\]

Each unordered edge pair is counted once; pairs sharing a graph endpoint are excluded.

For a proper segment crossing,

\[
\alpha(s,t)=\arccos\left(\lvert\hat s\cdot\hat t\rvert\right)\in[0,90^\circ],
\qquad
A(P)=\max_{\text{crossings touching }P}\cos\alpha.
\]

For misleading geodesics, let \(T=v_k\), \(g_i=\widehat{c(T)-c(v_i)}\), and let \(\mathcal A_i\) contain wrong branches in the current traversal direction. A branch is not “wrong” if \(T\) remains reachable through it.

\[
G_i=
\frac{
  [\angle(d_i^\*,g_i)-\min_{f\in\mathcal A_i}\angle(d_f,g_i)]_+
}{180^\circ},
\qquad
G(P)=\max_iG_i.
\]

For branch-fan confusability,

\[
F_i=
\frac{
 \#\{f\in\mathcal A_i:
 \operatorname{turn}(t_i^-,d_f)
 \le \operatorname{turn}(t_i^-,d_i^\*)+1^\circ\}
}{
 \max(1,\lvert\mathcal A_i\rvert)
},
\qquad
F(P)=\max_iF_i.
\]

This is deliberately rank-based: it asks whether a wrong branch is at least as visually continuous as the correct branch, without inventing an ungrounded smooth weighting curve.

The Ware branching term remains

\[
B(P)=\sum_{i=1}^{k-1}\max(0,\deg(v_i)-2).
\]

It is topological and therefore constant across paired arms. It stratifies intrinsic path difficulty in \(W(P)\), but cannot by itself certify a layout improvement.

## Gate policy

**Gated cells.**

- P1 compact: frozen v2 arm A → shipping Strata configuration.
- P1 full: frozen v2 arm F → shipping Strata full.
- P2 compact and full: same comparisons.
- Cyclic fixture: hierarchy plus all path gates whose floors are met.
- P3 remains composition/report-only because its effective graph duplicates P2.
- Slice classification is not part of path pairing, so the current full-mode A/B classification asymmetry no longer voids an otherwise identical dependency graph.

A missing/duplicate edge key, unresolved TFD endpoint, path-set mismatch, or VOID result fails the milestone. There is no owner visual override.

**Correct statistic bootstrap.** For lower-is-better metric \(m\), the observed p90 effect is

\[
\widehat\Delta_{.9}
=Q_{.9}(\{m_C(P)\})-Q_{.9}(\{m_B(P)\}),
\]

not the mean of paired deltas and not \(Q_{.9}(m_C-m_B)\).

Generate one deterministic \(B=1000\) index matrix using `mulberry32(20260704)`. For each draw:

1. Resample matched canonical anchor-edge keys \(n\)-out-of-\(n\), with replacement.
2. Bring along every sampled anchor’s baseline and candidate path block.
3. Compute \(Q_{.5}(C_b)-Q_{.5}(B_b)\) for the **p50 distribution**.
4. Separately compute \(Q_{.9}(C_b)-Q_{.9}(B_b)\) for the **p90 distribution**.
5. For a mean gate, separately compute \(\operatorname{mean}(C_b)-\operatorname{mean}(B_b)\).
6. Sort each replicate distribution and take its own 2.5%/97.5% percentile CI.

Thus a result labelled `p90` is a bootstrap CI on p90 itself. Per-edge metrics use the same procedure with individual canonical edge keys rather than anchor blocks.

**Floors and voids.**

- \(n<10\): report-only.
- p90 requires \(n\ge31\), correcting v3.1’s off-by-one: with `floor(0.9n)`, \(n=31\) is the first size with three observations above the selected order statistic.
- \(10\le n<31\): gate p50; report p90.
- Unmatched keys \(>20\%\) of `min(nBaseline,nCandidate)`: VOID.
- \(n=0\): VOID.
- For p90, if the 97.5% bound equals the maximum bootstrap replicate statistic, mark `P90_DEGENERATE` and apply the frozen fallback to p50; never report that p90 “passed.”
- Zero-width p50/mean intervals are valid: equality passes a no-regression gate but not a strict-improvement gate.

**Milestone composition: lexicographic, not compensatory.**

1. Every hierarchy/identity/determinism gate passes.
2. In every eligible cell, Ware \(W\) p50 and p90 must strictly improve: CI upper bound \(<0\).
3. Continuity, crossings-on-path, crossing-angle severity, geodesic tendency, branch-fan confusability and bend burden must each not regress at p90: CI upper bound \(\le0\); use the floor/degeneracy fallback above.
4. Report-only metrics never rescue a failed task gate.
5. Any gated-cell VOID means the milestone is not decided, therefore not passed.

This uses Ware’s published weights only inside the primary task score while retaining non-substitutable component vetoes. A weighted global “beauty score” is explicitly rejected.

**Frozen baselines.** The current [P1 frozen JSON](/Users/tusharsariya/Projects/excalidraw-tf/docs/strata-baselines/Q2_AUDIT_REPORT_P1.json) and [P2 frozen JSON](/Users/tusharsariya/Projects/excalidraw-tf/docs/strata-baselines/Q2_AUDIT_REPORT_P2.json) contain aggregates but no `perEdge` rows, so they cannot support a correct p50/p90 bootstrap.

v3.2 therefore needs a one-time, pre-candidate freeze from the pinned historical v2 revision containing:

- canonical per-edge keys and rendered polylines or complete derived edge rows;
- canonical path keys, anchor groups and all per-path scalar values;
- source revision, preset/card-mode identity, geometry constants, seed, \(B\), \(L\), replicas and schema version;
- headline summaries and SHA-256.

Normal CI must load this artifact—never call the v2 builder—and assert:

- exact SHA-256;
- exact expected edge/path populations and unique keys;
- summaries recomputed from raw rows equal the freeze register;
- geometry and sampling pins match;
- baseline artifacts and their hash manifest are unchanged in ordinary PRs.

A dedicated refreeze workflow may replace both artifact and normative register; ordinary gate tests must fail if either drifts.

## What to demote/drop

- **Raw vertical extent p50/p90:** demote to report-only. It measures the W4 band-height residual, not path-following difficulty. Literature does not isolate vertical from horizontal edge cost; retain it explicitly as an owner engineering prior.
- **Mean bands skipped:** report-only optimizer telemetry. It is useful for A2 but ignores actual path continuity, crossings and branch decisions.
- **Stacked band height, aggregate canvas height, W×H, aspect and area utilization:** report-only compactness diagnostics.
- **Global crossings/eligible pairs:** report-only. Purchase supports global crossings for mixed graph tasks, but Ware found crossings on the sought path—not total crossings—predicted shortest-path time.
- **24 px near-straight fraction and raw vertical-deviation median/mean/p95:** replace as gates with angle-based path continuity and bend burden. The pixel threshold is scale/constants-sensitive and assumes vertical displacement is uniquely harmful.
- **Hub centering and fan-out column rate:** report-only. They are incomplete in current full-mode scenes and are weaker than explicit branch-fan and geodesic trap metrics.
- **Raw edge length:** report-only. Ware’s geometric-length variables did not survive the regression; metro-map support is a design convention rather than direct impact-tracing evidence.
- **Keep collisions, containment and semantic direction:** promote/retain as exact structural gates, not readability scores.
- **A4 diff stability:** retain as a separate shipping gate; it should not be blended into readability.
