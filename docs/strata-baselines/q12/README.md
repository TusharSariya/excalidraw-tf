## Synthetic-P3 disclosure (R8-F4 stays open)

P3 (`staging-heldout-mesh`) is **self-authored**: generated by `scripts/generate-heldout-plan.mjs` (deterministic, mulberry32 seed 20260704 — the frozen v3.1 §12 seed). It is **out-of-tuning-distribution transfer material, NOT an independently sampled held-out plan.** Round-8 finding R8-F4 (no genuinely held-out preset exists) therefore stays **formally open** until a real independent plan re-runs the preset-parameterized W12 battery.

The generator and fixture were frozen (committed) in W12 WP1, **before any battery numbers existed for P3** (codex plan-review P2 freeze discipline).

## Fixture v2 (AMENDMENT-1)

v1 of the fixture fixed every resource to a single provider/account/region — a **generator artifact** that left the preset with zero slice-B (cross-band) edges, so every extent headline cell was frozen-VOID and extent transfer was unexercised. Under the labeled amendment AMENDMENT-1 in `docs/strata-view-w12-heldout-scale.md`, the fixture is versioned to **v2 for band structure ONLY** (3 account/region bands + cross-band audit/alert fan-ins; same seed, depth/hub/cycles unchanged; thresholds/metrics/definitions untouched). The v1 profile is preserved as `P3_DISTINCTNESS_PROFILE.v1.{json,md}`; the current profile files are v2.
